# CL4.2 results: 3D baseline, first pass (s = 32)

3D CL4.2 (`docs/laplace3d/tasks/CL4.2.md`). The author chose a first pass at s = 32 only,
p = 0 (2026-11-27); s = 64 waits for the author's decision.

## Setting

- n = 65, K = 32, the `poisson3d_n65_K32` splits (1,000 train, 200 test), learning grid
  s = 32, padding p = 0, modes 12³, D4's model (`FNO<5>`, 56,631,841 parameters), 500
  epochs of Adam at batch 20 (25,000 steps), seeds 42, 43, 44.
- VM, 2× A100 80 GB, one run per GPU (D8): seeds 42 then 43 on GPU 0, seed 44 on GPU 1,
  2026-11-27 09:46–13:20 UTC, commit `69c05f6`, Burn 0.23.0-pre.2, cuda, TF32 off
  (`cubek.toml`). Started by the coordinating session at the author's go; driver
  `~/sciml-rs/logs/cl4-2-driver.sh`, logs `~/sciml-rs/logs/cl4-2-*.log` on the VM.
- Before any run: `gpu_parity` 9/9 on cuda (with `flex`, the reference; the plan's first
  command lacked it, fixed in the plan).
- Evaluation: `predict_poisson3d` on cuda, the test split. Every run's mean error 3 matches
  its `metrics.csv` test_l2 at epoch 499 (relative difference ≤ 1.3e-7, tolerance 1e-5).
  Run directories distinct (the plan's `uniq -d` check printed nothing).
