## The label-check rule

The plan's first draft enforced the check from n = 33, reading CL2.1's 1.9e-13 as the
figure at D3's K. That figure was at K = (n − 1)/4 (K = 8 at n = 33, 16 at n = 65). At
K(n) = (n − 1)/2 the 3D check is about 4e-7 at n = 33 and 4e-10 at n = 65, the 2D
pattern, so the 2D rule (enforced for n ≥ 65) is kept.
